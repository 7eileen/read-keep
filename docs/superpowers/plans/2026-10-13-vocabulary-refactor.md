# 词汇册与生词本改造计划

执行方式：当前任务内逐项实现、测试并验收。范围已由用户扩展为七项改造，包含学习、动态间隔、首页统计、首次进入与导航。

目标：全部词汇保留来源，生词是独立的用户标记；独立词汇册可改名并同步；按词汇合并展示生词；统一底部记录入口，支持 TXT/CSV 和 DOCX。

数据：新增 notebooks 和 vocabulary 两类独立对象及按 owner_id 隔离的云端表。entries 保存每次遇见的释义、原句、笔记、回顾进度和 notebookId；vocabulary 按规范化词语保存 isUnknown。只去除 sample 演示记录，保留真实记录；删除 star 属性和全部收藏 UI。新导入的词默认非生词，已有生词重复导入保持其全局标记。

- [x] 1. 纯函数与回归测试：100 词选 20 词；重复词跨三册只显示一组，保留三份语境；改名、重名校验、空册、取消标记不删除、迁移幂等。
- [x] 2. 行级同步与数据库权限：四个新表、版本触发器、RPC、冲突合并与账号隔离；数据库迁移只新增结构，不批量清空真实数据。
- [x] 3. 词汇册列表、册名编辑、全部/生词筛选、单选和批量标记；生词本聚合详情与范围导出，保留完整 JSON 备份。
- [x] 4. 底部记录选择器、词汇 TXT/CSV 解析及预览、DOCX 正文解析；保留现有 PDF 与粘贴、词典、翻译和正文编辑。
- [x] 5. 移除收藏交互，更新文章选词与取消标记、回顾筛选和统计；无演示数据的新账号为空。
- [x] 6. 全部测试、构建与手机/桌面交互验收；两个专用 QA 账号的同步及越权验证；独立审查后准备发布，生产部署另行复验。

边界：CSV 引号、换行、BOM、公式注入；非法/超大 DOCX、空正文；改名重名/大小写空格；旧记录、空册及跨账号；取消标记后的来源和回顾进度保留。词形不做自动合并，大小写和多余空格归一化。

- [x] 7. 按规范化词语共享学习进度；独立事件记录与持久学习队列；先回忆再反馈，三种方式与两种范围，动态间隔及每日数量。
- [x] 8. 首页真实新增/复习统计、复习点亮日历、不同词汇/来源/上传文章分开计数；首次登录/访客选择及明确迁移入口。
- [x] 9. 全流程、离线恢复、跨设备、账号隔离、桌面/手机回归；按阶段提交可回退版本，全部验收后发布兼容版本（发布进度见验收记录）。

导航：首次进入 → 登录或访客 → 今天；主导航为今天 / 词汇册 / 文章 / 生词本 / 学习；全局底部记录 → 记录词汇 / 记录文章。学习范围独立于记忆方式。

学习算法：参考 SM-2 的难度因子随反馈调整，采用本产品三档反馈的简化调度，非原版 SM-2。历史事件保留时间、方式、来源和反馈；同词共享进度。删除来源或词汇册不会清除学习历史。

## 范围与数据

执行用户确认的七阶段改造。只清除带演示标记的数据，保留真实词汇、文章、笔记与原有回顾进度；没有清空生产账号。旧数据在客户端加载时幂等升级。词汇按大小写、首尾及连续空格归一化，不自动合并不同词形。

`entries` 保留每条来源记录，`notebooks` 独立保存册名和创建时间，`vocabulary` 保存跨来源共享的生词标记及旧进度基线。`review_events` 保存每次学习的时间、来源、范围、方式及反馈，`study_sessions` 保存待完成队列。新上传文章未选中的正文词语不会进入词汇统计。

## 导航与操作流程

首次进入 → 登录 / 访客使用 → 今天。已有会话自动恢复；访客数据保存在当前浏览器，账号弹窗提供明确迁移入口。

手机和电脑均有：今天 / 词汇册 / 文章 / 生词本 / 学习。

- 底部记录 → 记录词汇 → 粘贴或 TXT / CSV → 检查词汇与释义 → 命名 → 保存新词汇册 → 单选、多选或全选加入生词本。
- 底部记录 → 记录文章 → 文字 PDF / DOCX / TXT / 粘贴 → 编辑正文 → 点词或选短语 → 保存来源并标为生词。
- 学习 → 选择全部词汇或全部生词 → 选择英文回忆释义、释义回忆英文或原句填空 → 回忆 → 显示答案 → 忘记 / 模糊 / 记得。

## 删除影响

- 移出生词本：只取消整个词的生词标记，所有词汇册、来源、笔记、学习历史保留。
- 删除来源记录：删除该条释义、原句及笔记，保留其他来源和共享学习历史。
- 删除词汇册：删除该册及其所属来源记录、笔记，保留原文章、其他册和共享学习历史。
- 删除文章：现有文章删除对话框说明影响，已收录词汇来源保留。

删除原记录和词汇册前均提供具体影响提示，不将批量移出生词本伪装成删除源数据。

## 学习与同步边界

调度参考 [SM-2](https://www.super-memory.com/english/ol/sm2.htm) 的难度因子，按三档反馈简化，非原版算法或个人记忆能力的科学测量。初次反馈的下次间隔分别为 1 / 2 / 3 天；后续根据历史难度、连续记得次数和既有间隔变化。按北京时间统计学习日，同词多个来源轮换参与练习。

每日上限按已学习的不同词汇数计算，学习范围与方式共用上限；首页入口采用生词范围、英文回忆释义，与首页任务数量一致。无释义的词需补充释义，填空需有包含该词的原句。

旧版只保存累计进度，没有逐次学习时间，迁移保留其基线，不伪造历史日历。删除最后一个来源后保留进度，但该词不再产生无来源任务。

离线修改先写账号专属缓存，恢复网络或点击同步后合并；同一条记录发生不同修改时提供冲突处理，独立记录自动合并。断网首次打开且没有网页缓存时，不保证加载应用。跨设备可在打开页面或点击同步后读取云端；尚未上传的离线修改只在原设备。

本版不包含扫描 PDF OCR、旧 `.doc`、Excel 导入；DOCX 读取正文，不保留原文复杂版式。CSV 导出所选词汇的全部来源，完整 JSON 包含全部备份对象。文件上传控件和下载落盘未做浏览器自动化端到端验证，解析和导出内容已通过程序测试。
